## Branch
- 각 브랜치의 특징 및 역할 설명
- main: 배포 가능 상태 브랜치
- develop: 개발 브랜치
- release: 배포 브랜치(DB는 운영쪽, APP은 개발쪽으로 실제 데이터로 테스트 용으로 활용)
- hotfix: 긴급 상황 시 PR을 거치지 않고 바로 시스템 안정화를 위해 사용
- feature: 개발할 기능별로 생성/소멸하는 브랜치
